# Bobrova algoritemska misija

V naboru je vseh 26 kartic iz sklopa Algoritmi. Ob vsakem igranju se naključno izbere 9 kartic.

Končno geslo je:

```text

```

## Objavljanje na GitHub Pages

Naloži datoteke `index.html`, `style.css`, `script.js`, `README.md` in mapo `images`, nato vključi **Settings → Pages → Deploy from a branch → main → /root**.
